# Multi-Language Mini Projects

A compact collection of small, real, runnable projects across different programming languages.  
The goal is to show practical problem solving, clean structure, and language variety without empty or fake repositories.

## Projects

| Project | Language | What it does |
|---|---|---|
| python-file-sorter | Python | Organizes files by extension into folders. |
| js-expense-tracker | HTML/CSS/JavaScript | Tracks expenses in the browser using localStorage. |
| typescript-form-validator | TypeScript | Validates registration form data with typed results. |
| php-file-size-api | PHP | Returns file-size information as JSON. |
| csharp-notes-cli | C# | Simple command-line note manager. |
| cpp-algorithms | C++ | Binary search and sorting examples. |
| java-student-grades | Java | Calculates student grade averages. |
| go-word-counter | Go | Counts words and characters from text input. |
| rust-unit-converter | Rust | Converts temperature and distance units. |
| sql-library-schema | SQL | Small relational database schema for a library system. |
| bash-backup-checker | Bash | Checks whether important backup folders exist. |
| powershell-system-report | PowerShell | Creates a basic Windows system report. |

## Why this collection exists

- To practice multiple programming languages.
- To keep every project small, clear, and readable.
- To build a stronger GitHub profile with real code and honest progress.
- To make future improvements easy: tests, screenshots, CI, and documentation.
